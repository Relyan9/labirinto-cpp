# Labirinto Escuro (C++)

Jogo de exploração baseado em decisões, com eventos aleatórios e múltiplos caminhos.

## Funcionalidades
- Movimentação por direções (N, S, L, O)
- Sistema de vida, sorte, força e ouro
- Armadilhas e eventos aleatórios
- Final com chance baseada nos atributos
